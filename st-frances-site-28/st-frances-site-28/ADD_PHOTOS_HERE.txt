Put gallery photos in this folder (assets/images/gallery/) using these
file names, and they will show up on the Gallery page for the matching
school automatically.

For the Omolere page (now at primary/gallery.html), use:
omolere-1.jpg, omolere-2.jpg, omolere-3.jpg, omolere-4.jpg, omolere-5.jpg, omolere-6.jpg

For the St. Frances' Academy page (now at secondary/gallery.html), use:
stfrances-1.jpg, stfrances-2.jpg, stfrances-3.jpg, stfrances-4.jpg, stfrances-5.jpg, stfrances-6.jpg

Notes:
JPG or PNG both work. Square or landscape photos look best in the grid.
If a file is missing, that tile shows a plain placeholder icon instead,
so nothing breaks while you are still collecting photos.
Keep the file names exactly as written above, all lower case, no spaces.

Also put these in assets/images/ (used across every page):
group-logo.png       - shown in the top navigation bar on all pages
omolere-logo.png     - shown on the Omolere primary home page
stfrances-logo.png   - shown on the St. Frances' Academy home page
chairman.jpg          - shown next to the Proprietor/Chairman's welcome note on the group homepage (index.html). Square or portrait photos look best. If missing, that box just shows a plain placeholder message, so nothing breaks.

Staff photos go in assets/images/staff/ using these file names (School
Management/Staff page). Square, front-facing headshots work best. If a
file is missing, that card just shows initials in a circle instead, so
nothing breaks while you're still collecting photos.

For the Omolere page (primary/staff.html):
primary-head-teacher.jpg
primary-deputy-head-teacher.jpg
primary-admissions-officer.jpg

For the St. Frances' Academy page (secondary/staff.html):
secondary-principal.jpg
secondary-vice-principal.jpg
secondary-exams-officer.jpg

Those same two files (primary-head-teacher.jpg and secondary-principal.jpg)
are also used for the "Welcome Address" section on each school's home page
(primary/index.html and secondary/index.html) -- one photo, shown in two
places. Unlike the staff page (small square headshot), the homepage
welcome section shows the full photo without cropping, so a normal
portrait-style photo (not necessarily square) works well there too.
